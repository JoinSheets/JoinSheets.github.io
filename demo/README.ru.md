Браузерный конструктор таблиц:

- работает с плоскими таблицами;
- формирует датасет на основе операций с множествами (объединение, вычитание, пересечение и проч.);
- парсит основные типы данных (текст, даты, числа, булевые или пустые значения);
- позволяет рассчитывать поля (агрегация, формулы, разрешение коллизий на основе приоритетов);
- поддерживает основные операции с таблицами (поиск, сортировка, группировка, фильтрация);
- выгружает результат в Excel/CSV.

Без внешних зависимостей, без серверной части, без установки —
просто скачивайте репозиторий и открывайте `index.html`.
Работает как статический сайт, полностью локально.

Опциональный субмодуль [JoinSheetsImport](https://github.com/JoinSheets/JoinSheetsImport)
добавляет кнопку «Импорт» для загрузки данных из Excel.

В комплекте идет готовый демо-набор ([`sample-data/`](sample-data/)) —
для быстрого старта на простых примерах.
