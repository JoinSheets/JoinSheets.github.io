# JoinSheets

A browser-only table builder: join flat data sources, compute fields, and
export to Excel/CSV. No server, no install — download the repository and open
`index.html`, or try it right here.

{{< button "/demo/" "Try the demo" >}} {{< button "/docs/" "Read the docs" >}}

## What it does

- Works with flat tables.
- Builds a dataset through set operations (union, subtraction, intersection, etc.).
- Parses core data types (text, dates, numbers, booleans, or empty values).
- Computes fields (aggregation, formulas, priority-based collision resolution).
- Supports core table operations (search, sort, group, filter).
- Exports the result to Excel/CSV.

Source code: [github.com/JoinSheets/JoinSheets](https://github.com/JoinSheets/JoinSheets).
