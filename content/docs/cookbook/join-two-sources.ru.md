**Задача:** есть выгрузка CRM (клиенты) и выгрузка ERP (цены и остатки),
нужна одна таблица с обеими.

1. На экране **Data** отметь оба источника.
2. Появится строка связки для второго источника. Выбери тип связки (`LEFT`,
   чтобы оставить все строки CRM даже без пары в ERP — обычно разумный
   вариант по умолчанию) и сопоставляемое поле с каждой стороны (например,
   `customer_id` ↔ `client_ref`).
3. Отметь нужные поля из каждого источника.
4. Открой **Table** — в результате одна строка на каждую совпавшую (или
   несовпавшую, для `LEFT`/`RIGHT`/`FULL`) пару.

*(Скоро появятся новые рецепты — условия, формулы, группировка с
агрегатами.)*
