## 1. Open the app

Download the [JoinSheets](https://github.com/JoinSheets/JoinSheets) repository
and open `index.html` in a browser — no install, no server. Or just use the
[live demo](/demo/) on this site.

## 2. Pick your sources

On the **Data** screen, check the sources you want and the fields you need
from each. If you have more than one source, join them.

## 3. Shape the result

On the **Fields** screen, pick which columns to show, rename them, or compute
new ones from a formula.

## 4. Work with the table

Switch to **Table** to search, sort, group, and filter the result, then
export it to Excel or CSV.
