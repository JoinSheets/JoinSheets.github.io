## 1. Открой приложение

Скачай репозиторий [JoinSheets](https://github.com/JoinSheets/JoinSheets) и
открой `index.html` в браузере — без установки, без сервера. Либо используй
[живое демо](/demo/) на этом сайте.

## 2. Выбери источники

На экране **Data** отметь нужные источники и поля из каждого. Если источников
больше одного — свяжи их.

## 3. Настрой результат

На экране **Fields** выбери, какие столбцы показать, переименуй их или
посчитай новые по формуле.

## 4. Работай с таблицей

Перейди на **Table**, чтобы искать, сортировать, группировать и
фильтровать результат, затем выгрузи его в Excel или CSV.

*(Подробное руководство появится позже — пока см.
[Руководство пользователя](../user-guide/) по каждому экрану.)*
