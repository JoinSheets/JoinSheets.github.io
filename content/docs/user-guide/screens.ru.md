В JoinSheets три экрана, переход между ними — через верхнее меню.

## Data

Источники, связи между ними и условия по сырым полям — то, что в SQL идёт
после `FROM`/`WHERE`. Выбери нужные источники и поля, затем свяжи их
(left/right/inner/full), если источник не один.

## Fields

То, что идёт после `SELECT`: какие столбцы будут в результате и как они
считаются — поле как есть, переименованное/типизированное поле, разрешение
коллизии между несколькими входами по весам, либо формула.

## Table

Результат: поиск и фильтр по столбцу, сортировка (клик по заголовку или
расширенная панель для нескольких уровней), группировка с агрегатами по
группе, выгрузка в Excel или CSV.
