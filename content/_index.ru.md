# Браузерный конструктор таблиц

Объединяет плоские источники данных по ключу, считает поля и выгружает
результат — без сервера, без установки, и ничего не уходит с вашего
компьютера.

## Что умеет

{{< grid "3" >}}
{{< column >}}
<span class="feature-title">Объединяет таблицы</span>

Собирает источники данных по ключу через операции с множествами —

## Почему JoinSheets

- **Без сервера** — скачайте репозиторий и откройте `index.html`; вот и
  вся установка.
- **Данные остаются у вас** — JoinSheets только читает файлы, на которые
  вы ему указали. Ничего не отправляется и не отслеживается.
- **Без сборки** — без бандлера, без пакетного менеджера, без шага
  сборки; обычные файлы, работает прямо с `file://`.
- **Открытый код** — лицензия Apache-2.0, код открыт на GitHub: читайте,
  форкайте, предлагайте свои изменения.
