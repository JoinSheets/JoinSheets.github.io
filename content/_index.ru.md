# Браузерный конструктор таблиц

Объединяет плоские источники данных по ключу, считает поля и выгружает
результат — без сервера, без установки, и ничего не уходит с вашего
компьютера.

## Что умеет

{{< grid "3" >}}
{{< column >}}
<span class="feature-title">Объединяет таблицы</span>

Собирает источники данных по ключу через операции с множествами —
объединение, вычитание, пересечение и другие.
{{< /column >}}
{{< column >}}
<span class="feature-title">Понимает любые данные</span>

Текст, даты, числа, булевые или пустые значения — типизируются и
проверяются автоматически.
{{< /column >}}
{{< column >}}
<span class="feature-title">Считает поля</span>

Агрегация, формулы, разрешение коллизий на основе приоритетов, когда
источники расходятся.
{{< /column >}}
{{< column >}}
<span class="feature-title">Работает с таблицей</span>

Поиск, сортировка, группировка и фильтрация объединённого результата —
прямо на экране.
{{< /column >}}
{{< column >}}
<span class="feature-title">Сквозная работа</span>

Данные приходят и уходят в виде таблиц — импорт из Excel, работа с
результатом, выгрузка обратно в Excel или CSV.
{{< /column >}}
{{< /grid >}}

## Почему JoinSheets

{{< grid "2" >}}
{{< column >}}
**Без сервера**

Скачайте репозиторий и откройте `index.html` — вот и вся установка.
{{< /column >}}
{{< column >}}
**Данные остаются у вас**

JoinSheets только читает файлы, на которые вы ему указали. Ничего не
отправляется и не отслеживается.
{{< /column >}}
{{< column >}}
**Без сборки**

Без бандлера, без пакетного менеджера, без шага сборки — обычные файлы,
работает прямо с `file://`.
{{< /column >}}
{{< column >}}
**Открытый код**

Лицензия Apache-2.0, код открыт на GitHub — читайте, форкайте, предлагайте
свои изменения.
{{< /column >}}
{{< /grid >}}
